# گزارش آماده‌سازی پروژه AvidKiya

تاریخ انجام: 2026-07-07

## کارهای انجام‌شده

- ریپازیتوری از GitHub کلون شد و سورس اصلاح شد.
- داده‌های نمونه/دموی CMS صفر شد تا سایت در نصب تازه، خام و بدون محتوای از قبل پرشده بالا بیاید.
- زبان پیش‌فرض سایت از فارسی به انگلیسی تغییر کرد.
- متادیتای پیش‌فرض فارسی و برند قبلی پاک شد و به مقدار عمومی `New Site` تغییر کرد.
- پنل مدیریت مخفی `/kiya/panel` در بخش Identity بهتر شد:
  - آپلود لوگو اضافه شد.
  - پیش‌نمایش لوگو اضافه شد.
  - حذف لوگو اضافه شد.
  - تنظیم نام برند، حرف لوگو، رنگ اصلی و رنگ Accent اضافه/مرتب شد.
- نمایش لوگو در هدر اصلاح شد؛ اگر تصویر لوگو تنظیم شود، به‌جای حرف نمایش داده می‌شود.
- باگ دکمه جستجو در موبایل/هدر رفع شد؛ کامپوننت جستجو دیگر داخل wrapper مخفی‌شده قرار ندارد.
- منوی همبرگری فقط برای موبایل باقی ماند و در دسکتاپ همان منوی هدر نمایش داده می‌شود.
- واحد پول فروشگاه و فاکتور به تومان تغییر کرد:
  - محصولات جدید پنل با `TMN` ساخته می‌شوند.
  - فاکتور فروشگاه به‌صورت پیش‌فرض `TMN` دارد.
  - نمایش قیمت فروشگاه به `Toman` تغییر کرد.
- اتصال پرداخت فروشگاه پیاده‌سازی شد:
  - `/api/shop/checkout`
  - اتصال زرین‌پال با `ZARINPAL_MERCHANT_ID`
  - حالت sandbox با `ZARINPAL_SANDBOX=true`
  - پشتیبانی از لینک پرداخت خارجی با `PAYMENT_EXTERNAL_URL`
  - callback/verify زرین‌پال در `/api/shop/payment/verify`
- صدور فاکتور بدون نیاز به لایسنس پیاده‌سازی شد:
  - `/api/shop/invoice`
  - دانلود فاکتور HTML قابل Print/Save as PDF از مرورگر
- بخش هدیه‌ها در منوی اصلی و جستجو اضافه شد و صفحه `/gifts` با empty state قابل تنظیم از پنل آماده است.
- بخش Shop بازنویسی شد تا در حالت انگلیسی متن فارسی مستقیم نمایش ندهد.
- Blog و Announcements دیگر محتوای نمونه فارسی fallback نشان نمی‌دهند؛ فقط محتوای واقعی CMS نمایش داده می‌شود.
- Calendar در زبان انگلیسی، تقویم و متن انگلیسی نمایش می‌دهد و در حالت فارسی همچنان حالت تقویم ایرانی را نگه می‌دارد.
- Quote پیش‌فرض فارسی حذف و با متن‌های عمومی انگلیسی جایگزین شد.
- تنظیم ESLint عملی‌تر شد تا با الگوی localStorage hydration پروژه، lint خطا ندهد.

## تست‌های انجام‌شده

```bash
npm run typecheck
npm run build
npm run lint
```

نتیجه:

- TypeScript: موفق
- Build production: موفق
- ESLint: موفق با چند warning غیر بحرانی

## نکته‌های مهم برای نصب

```bash
npm install
npm run dev
```

پنل مدیریت:

```text
/kiya/panel
```

رمز پیش‌فرض پنل مخفی طبق پروژه قبلی همچنان:

```text
admin
```

بعد از اولین ورود، از بخش Settings رمز را عوض کنید.

## نکته باقی‌مانده

پروژه خیلی بزرگ است و هنوز در بعضی APIها و صفحات داخلی Planner/Admin متن‌های فارسی hard-coded وجود دارد. بخش‌های اصلی سایت، CMS، فروشگاه، هدر، جستجو، بلاگ، اعلان‌ها و حالت نصب خام اصلاح شدند و build کاملاً موفق است. برای انگلیسی‌سازی صددرصد همه پیام‌های API و تمام صفحات Planner داخلی، یک مرحله refactor کامل i18n جداگانه پیشنهاد می‌شود.
