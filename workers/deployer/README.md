# 🚀 AvidKiya Deployer

ابزار نصب خودکار پلتفرم اَوید کیا روی حساب Cloudflare — بدون نیاز به رفتن دستی به ۵ صفحه مختلف داشبورد.

## این ابزار چیکار می‌کند؟

با وارد کردن فقط یک **API Token**، این Worker به‌طور خودکار روی حساب Cloudflare شما:

1. یک **KV Namespace** می‌سازد (برای CMS/Cache)
2. یک **D1 Database** می‌سازد و Schema پایه را روی آن اجرا می‌کند
3. یک **Cloudflare Pages Project** می‌سازد (و در صورت دادن اطلاعات گیت‌هاب، مستقیم به ریپوی شما وصلش می‌کند تا هر `git push` خودکار دیپلوی شود)
4. **Environment Variables** لازم (`ADMIN_TOKEN`, `JWT_SECRET`, و اختیاری `TELEGRAM_BOT_TOKEN`) را تنظیم می‌کند
5. Binding های KV و D1 را به پروژه Pages وصل می‌کند

نتیجه: در کمتر از یک دقیقه، یک نسخه کاملاً کار کن از سایت روی `https://avidkiya-xxxxx.pages.dev` دارید.

## نصب Deployer (فقط یک‌بار لازم است)

```bash
cd workers/deployer
npx wrangler deploy
```

بعد از دیپلوی، یک آدرس مثل `https://avidkiya-deployer.YOUR_SUBDOMAIN.workers.dev` می‌گیرید — همین را در مرورگر باز کنید.

## استفاده

1. آدرس Deployer را باز کنید
2. روی «دریافت توکن کلودفلر» بزنید — یک توکن با دسترسی‌های لازم (Workers, KV, D1, Pages) بسازید
3. توکن را در فیلد وارد کنید
4. (اختیاری) یوزرنیم و نام ریپوی گیت‌هاب‌تان را وارد کنید تا دیپلوی خودکار وصل شود
5. روی «نصب خودکار پلتفرم» بزنید

## مدیریت نصب‌های قبلی

از بخش «مدیریت نصب‌های قبلی» می‌توانید:
- لیست همه‌ی نصب‌های `avidkiya-*` روی حسابتان را ببینید
- `ADMIN_TOKEN` یک نصب را عوض کنید (بدون نیاز به ورود به پنل مدیر)
- یک نصب را کامل حذف کنید

## نکات امنیتی

- این ابزار توکن Cloudflare شما را ذخیره نمی‌کند — فقط برای همان درخواست استفاده می‌شود
- بعد از اولین ورود به `/kiya/panel`، حتماً رمز پیش‌فرض `admin` را عوض کنید
- توکن Cloudflare را فقط با دسترسی‌های حداقلی (Workers, KV, D1, Pages — نه Full Access) بسازید
